# ECLIPSE
### Atajos de navegación:
- **Ctrl + Shift + R**: Abrir un archivo por nombre.
- **Ctrl + E**: Mostrar una lista de los archivos abiertos.
- **Ctrl + Shift + T**: Buscar una clase.
- **Ctrl + Shift + F**: Formatear el código.
- **Ctrl + Shift + L**: Mostrar todos los atajos de teclado.
- **Ctrl + Tab**: Cambiar entre pestañas abiertas.

### Atajos de edición de código:
- **Ctrl + D**: Eliminar la línea actual.
- **Ctrl + /**: Comentar o descomentar la línea seleccionada.
- **Ctrl + Shift + /**: Comentar el bloque seleccionado.
- **Ctrl + Shift + \**: Descomentar el bloque seleccionado.
- **Ctrl + Space**: Autocompletar código.
- **Ctrl + Shift + F**: Formatear el código.

### Atajos de depuración:
- **F11**: Ejecutar en modo depuración.
- **Ctrl + F11**: Ejecutar la aplicación normalmente.
- **F5**: Entrar en el código durante la depuración.
- **F6**: Paso a paso (ejecutar una línea de código sin entrar en métodos).
- **F8**: Continuar la ejecución.
- **Shift + F5**: Detener la depuración.

### Atajos de refactorización:
- **Alt + Shift + R**: Cambiar nombre de variable, método o clase.
- **Alt + Shift + M**: Extraer un método.
- **Alt + Shift + L**: Extraer una variable.
- **Alt + Shift + C**: Cambiar la firma del método.

### Atajos de búsqueda:
- **Ctrl + H**: Buscar en el proyecto.
- **Ctrl + Shift + F**: Buscar en todo el código.
- **Ctrl + Shift + G**: Buscar todas las referencias de un método/clase/variable.

### Atajos para el panel de problemas:
- **Ctrl + 3**: Abrir la vista de "Quick Access" (acceso rápido).
- **Ctrl + Shift + I**: Ver el "Quick Fix" (solución rápida) para problemas.

### Otros:
- **Ctrl + Shift + P**: Ir al paréntesis de cierre o apertura correspondiente.

### Atajos de Teclado en IntelliJ IDEA

## Navegación

- **Ir a la definición**: `Ctrl + Click`  
  Esto te lleva directamente a la definición de una clase, método o variable.

- **Ir a la declaración**: `Ctrl + B` (Windows/Linux) o `Cmd + B` (Mac)  
  Similar al anterior, pero también se puede usar en variables y métodos.

- **Ir a la línea**: `Ctrl + G` (Windows/Linux) o `Cmd + G` (Mac)  
  Te permite ir directamente a una línea específica del archivo.

- **Buscar archivo**: `Ctrl + Shift + N` (Windows/Linux) o `Cmd + Shift + O` (Mac)  
  Abre el cuadro de búsqueda para buscar archivos por nombre.

- **Buscar clase**: `Ctrl + N` (Windows/Linux) o `Cmd + O` (Mac)  
  Busca clases en tu proyecto rápidamente.

- **Buscar símbolo**: `Ctrl + Shift + Alt + N` (Windows/Linux) o `Cmd + Shift + O` (Mac)  
  Busca métodos, variables o cualquier otro símbolo en el código.

## Edición

- **Autocompletado de código**: `Ctrl + Space` (Windows/Linux) o `Cmd + Space` (Mac)  
  Completa código de manera inteligente.

- **Refactorizar código**: `Ctrl + Shift + R` (Windows/Linux) o `Cmd + Shift + R` (Mac)  
  Refactoriza el código, como renombrar métodos o variables.

- **Cambiar firma del método**: `Ctrl + F6` (Windows/Linux) o `Cmd + F6` (Mac)  
  Permite modificar la firma de un método (parámetros, tipo de retorno).

- **Duplicar línea o bloque de código**: `Ctrl + D` (Windows/Linux) o `Cmd + D` (Mac)  
  Duplica la línea actual o el bloque de código seleccionado.

- **Eliminar línea**: `Ctrl + Y` (Windows/Linux) o `Cmd + Backspace` (Mac)  
  Elimina la línea actual.

- **Comentar/Descomentar línea de código**: `Ctrl + /` (Windows/Linux) o `Cmd + /` (Mac)  
  Comenta o descomenta la línea o bloque de código seleccionado.

- **Reformatear código**: `Ctrl + Alt + L` (Windows/Linux) o `Cmd + Option + L` (Mac)  
  Reformatea el código automáticamente según las reglas de estilo configuradas.

## Búsqueda y Reemplazo

- **Buscar en el archivo actual**: `Ctrl + F` (Windows/Linux) o `Cmd + F` (Mac)  
  Abre el cuadro de búsqueda en el archivo actual.

- **Buscar en todo el proyecto**: `Ctrl + Shift + F` (Windows/Linux) o `Cmd + Shift + F` (Mac)  
  Busca en todos los archivos del proyecto.

- **Buscar y reemplazar**: `Ctrl + R` (Windows/Linux) o `Cmd + R` (Mac)  
  Abre el cuadro de búsqueda y reemplazo en el archivo actual.

- **Buscar todos los usos de una variable o método**: `Ctrl + Shift + F7` (Windows/Linux) o `Cmd + Shift + F7` (Mac)  
  Muestra todos los lugares donde se usa la variable o el método seleccionado.

## Depuración

- **Poner un punto de interrupción**: `Ctrl + F8` (Windows/Linux) o `Cmd + F8` (Mac)  
  Coloca o quita un punto de interrupción en la línea actual.

- **Iniciar depuración**: `Shift + F9` (Windows/Linux) o `Cmd + Shift + D` (Mac)  
  Inicia la depuración del proyecto.

- **Ejecutar hasta el punto de interrupción**: `Alt + F9` (Windows/Linux) o `Option + F9` (Mac)  
  Ejecuta el código hasta llegar al punto de interrupción.

### Paso a paso en la depuración:
- **Paso sobre (Step Over)**: `F8` (Windows/Linux/Mac)
- **Paso a entrar (Step Into)**: `F7` (Windows/Linux/Mac)
- **Paso atrás (Step Out)**: `Shift + F8` (Windows/Linux/Mac)

## Ventanas y Herramientas

- **Abrir terminal**: `Alt + F12` (Windows/Linux) o `Cmd + Option + T` (Mac)  
  Abre el terminal dentro de IntelliJ IDEA.

- **Mostrar/ocultar la ventana de herramientas**: `Ctrl + Shift + F12` (Windows/Linux) o `Cmd + Shift + F12` (Mac)  
  Maximiza la ventana de editor y oculta las ventanas de herramientas.

- **Abrir la vista de estructura del archivo**: `Ctrl + F12` (Windows/Linux) o `Cmd + F12` (Mac)  
  Muestra la estructura del archivo actual (métodos, clases, etc.).

- **Cambiar entre pestañas abiertas**: `Ctrl + Tab` (Windows/Linux) o `Cmd + Tab` (Mac)  
  Navega entre las pestañas abiertas.

## Otras Utilidades

- **Ver todas las acciones disponibles**: `Ctrl + Shift + A` (Windows/Linux) o `Cmd + Shift + A` (Mac)  
  Muestra un cuadro de búsqueda de todas las acciones y comandos disponibles en IntelliJ IDEA.

- **Abrir la configuración de IntelliJ IDEA**: `Ctrl + Alt + S` (Windows/Linux) o `Cmd + ,` (Mac)  
  Abre la configuración de la IDE.

- **Ver los cambios en el control de versiones (Git, SVN)**: `Ctrl + K` (Windows/Linux) o `Cmd + K` (Mac)  
  Muestra los cambios locales para confirmar en el sistema de control de versiones.

## Navegación Rápida

- **Cambiar entre archivos recientes**: `Ctrl + E` (Windows/Linux) o `Cmd + E` (Mac)  
  Muestra una lista de archivos abiertos recientemente.

- **Ver la lista de métodos y funciones**: `Ctrl + F12` (Windows/Linux) o `Cmd + F12` (Mac)  
  Muestra una lista de todos los métodos y funciones en el archivo actual.

## Atajos para Herramientas de Pruebas

- **Ejecutar las pruebas**: `Ctrl + Shift + F10` (Windows/Linux) o `Cmd + Shift + R` (Mac)  
  Ejecuta la prueba seleccionada o la configuración de ejecución actual.

- **Ver el resultado de las pruebas**: `Ctrl + Shift + F9` (Windows/Linux) o `Cmd + Shift + F9` (Mac)  
  Muestra los resultados de las pruebas.

## Atajos de Proyecto y Estructura

- **Ver la estructura del proyecto**: `Alt + 1` (Windows/Linux) o `Cmd + 1` (Mac)  
  Muestra la ventana del proyecto.

- **Ver la lista de cambios**: `Alt + 9` (Windows/Linux) o `Cmd + 9` (Mac)  
  Abre la vista de cambios del proyecto.

## Bonus: Atajos Personalizados

Puedes personalizar los atajos según tus preferencias. Ve a **File > Settings > Keymap** (o **IntelliJ IDEA > Preferences > Keymap** en Mac) para ver y modificar los atajos.

Dominar estos atajos te permitirá mejorar tu eficiencia y ser un verdadero dev 10x. ¡A practicar! 😎
