______________SUBIR REPOS COMO SI FUERAN MIOS PARA PRACTICAR_____________________

1. clonar el repo 
	`git clone https://...git`
2. CAMBIAR EL NOMBRE DE LA CARPETA 
	`mv original-repo nuevo-nombre`
3. MOVERSE AL NUEVO REPO
	cd nuevo-nombre
4. QUITAR EL ORIGIN DEL REPO 
	git remote remove origin
5. CREAR NUEVO REPO Y AÑADIR UBICACIÓN DEL MÍO, SIN README NI GITIGNORE NI NADA
	git remote add origin https://...git
5. SUBIR A MI REPO
	git push -u origin main (o master, dependiendo del nombre)


_________________________CAMBIAR NOMBRE DEL PROYECTO EN INTELLIJ IDEA_____________
1. RENOMBRAR LA CARPETA
2.ABRIR INTELLIJ 
3. SELECCIONAR OPEN Y NAVEGAR HASTA LA CARPETA DEL PROYECTO RENOMBRADA (NUEVO-NOMBRE)
4. CAMBIAR NOMBRE DENTRO DE IDEA. ABRIR PANEL VIEW > TOOL WINDOWS > PROJECT
5. CLIC DERECHO EN RAIZ > REFACTOR > RENAME Y PONER NUEVO NOMBRE
6. CAMBIAR NOMBRE EN CONFIG DEL PROJ.
	FILE > PROJECT > STRUCTURE > PROJECT. Y CAMBIAR EL NOMBRE.
7.ASEGURARSE QUE "PROJECT SDK" (JDK DEL PROJECT) NO SE HAYAN VISTO AFECTADAS.
8. QUE .IML Y .IDEA NO HAGAN REFERENCIA AL NOMBRE ANTIGUO. VERIFICAR SI HAY PROBLEM
9.SINCRONIZAR. FILE > INVALIDATE CACHES > RESTART
